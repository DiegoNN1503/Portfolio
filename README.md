# 💼 Portfólio Pessoal — Diego Nicolau Norberto

Este projeto é meu portfólio pessoal desenvolvido com **HTML, CSS e JavaScript**, criado com o objetivo de apresentar minha trajetória de aprendizado, habilidades e evolução na área de Desenvolvimento Web.

O site foi construído aplicando conceitos fundamentais de desenvolvimento front-end, com foco em organização de código, semântica, responsividade e experiência do usuário.

## 🚀 Funcionalidades

* Alternância entre tema claro e escuro
* Salvamento da preferência de tema utilizando Local Storage
* Filtro dinâmico de projetos por categoria
* Animações de entrada ao rolar a página
* Botão de retorno ao topo com rolagem suave
* Atualização automática do ano no rodapé
* Estrutura semântica e acessível
* Layout responsivo para diferentes dispositivos

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## 📚 Objetivo do Projeto

Este portfólio foi desenvolvido como parte do meu processo de aprendizado em desenvolvimento web. O objetivo é praticar conceitos modernos de construção de interfaces, organização de código e interatividade utilizando tecnologias fundamentais da web.

Além de servir como vitrine dos meus estudos e projetos, o site representa minha evolução como desenvolvedor e será continuamente atualizado conforme adquiro novos conhecimentos.
